# Reorganise calculator livestock tools

## What will change

- Move the invertebrate search, selected invertebrates and their separate checks directly beneath the fish controls.
- Replace the automatically displayed compatible-fish list with a clear optional action.
- Only calculate and show compatible fish after the person asks, with a simple way to hide the results again.

## Technical details

- Keep all scoring and compatibility rules unchanged.
- Reset the requested suggestions when the tank plan changes, so previously calculated advice is not shown for a different plan.
- Verify the calculator layout and interaction at desktop and mobile widths, then run the relevant tests and checks.
